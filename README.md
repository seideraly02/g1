# Qadam ENT Mobile

ҰБТ-ға дайындалуға арналған 19 экрандық мобильді интерфейс. Жоба Vue 3, TypeScript, `<script setup>` және Tailwind CSS арқылы жасалған. Интерфейс толық қазақ тілінде.

## Іске қосу

```bash
npm install
npm run dev
```

Өндірістік жинақ:

```bash
npm run build
```

## Негізгі маршруттар

- `/` — жылдам диагностика
- `/home` — басты бет
- `/subjects` — пәндер
- `/training` — жаттығулар
- `/progress` — ілгерілеу
- `/profile` — профиль

Қалған экрандар батырмалар мен карточкалар арқылы байланыстырылған.
